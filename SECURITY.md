# Security reporting

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature when the repository has private vulnerability reporting enabled. If that feature is unavailable, ask the maintainer for a private reporting channel without posting exploit details or sensitive store information in a public issue.

Include the affected plugin/version, relevant WordPress/WooCommerce/provider versions, the required account permissions, a minimal reproduction and observed impact. Use synthetic products and addresses. Do not include credentials, customer data or real vendor mailboxes.

Version 1.0.0 is the initial implementation; no response-time commitment or broader support policy is implied. Maintainers must confirm the private reporting channel before public release. No unverified email address or security contact is provided.
